## Key Claim
XCENA argues that the real bottleneck in AI inference is not raw compute but the structural round-trip that data makes between DRAM, CPU, and GPU on every token generated — and has built a computational memory controller chip that places processing capability directly beside DRAM to eliminate that loop.

## Evidence / Context
- Raised $135M Series B at $570M valuation; total funding now $185M
- Founded 2022 by Jin Kim (CEO), Dohun Kim (CTO), Harry Juhyun Kim (CPO) — all Samsung and SK Hynix veterans
- Product: MX1 chip — a computational memory controller that moves compute to DRAM rather than routing data out to GPU/CPU
- Architecture claim: current AI inference requires data to leave memory → CPU preprocessing → GPU computation → back to memory, on every token; XCENA short-circuits this
- Mass production at Samsung foundry scheduled end of 2026; revenue expected 2027
- Offices in South Korea and the U.S.
